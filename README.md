# Arduino Uno + VS1053 MP3 Audio Shield

Демонстрационный проект полного функционала звуковой платы (шилда) **VS1053B MP3 Shield** (Geeetech / SparkFun / LC Tech) на базе микроконтроллера **ATmega328P (Arduino Uno)** с воспроизведением треков с **MicroSD карты**.

---

## 🎧 Возможности прошивки

1. **Фоновое воспроизведение (DREQ Interrupt)**:
   - Аудиопоток передается в VS1053 по аппаратному прерыванию DREQ (INT0, Pin 2), поэтому воспроизведение не прерывается и не заикается во время работы других подсистем.
2. **Аппаратный синус-тест (Sine Test)**:
   - Встроенная в DSP чипа VS1053 проверка ЦАП и аналогового тракта (наушников/динамиков) генерацией тестового тона 440 Гц даже без вставленной SD-карты.
3. **Аппаратный эквалайзер (DSP Tone Control)**:
   - Регулировка усиления басов (`SCI_BASS`: +0..+15 dB) с настраиваемой частотой среза фильтра.
   - Регулировка высоких частот (-8..+7 dB).
4. **Пространственный 3D-звук (EarSpeaker)**:
   - Встроенный в процессор VS1053 пространственный расширитель стереобазы (4 режима: выкл, минимальный, нормальный, максимальный эффект).
5. **Интерактивный консольный интерфейс (Serial CLI 115200 бод)**:
   - Полное управление треками, громкостью, эквалайзером и чтением статусных регистров прямо из монитора порта.
6. **Чтение содержимого MicroSD**:
   - Сканирование каталога SD-карты с выводом имен файлов и их размеров.

## 📌 Распиновка (Pinout для Arduino Uno)

| Сигнал | Пин Arduino Uno | Назначение |
| :--- | :--- | :--- |
| **MOSI** | Digital 11 (PB3) | Линия передачи данных SPI |
| **MISO** | Digital 12 (PB4) | Линия приема данных SPI |
| **SCK** | Digital 13 (PB5) | Тактовый сигнал SPI |
| **XCS** | Digital 9 (PB1) | Выбор чипа управления VS1053 (SCI) |
| **XDCS** | Digital 8 (PB0) | Выбор чипа данных VS1053 (SDI / BSYNC) |
| **DREQ** | Digital 2 (PD2) | Запрос данных (внешнее прерывание INT0) |
| **SD_CS**| Digital 4 (PD4) | Выбор карты памяти MicroSD |
| **RESET**| Reset Arduino | Аппаратный сброс |

## 📂 Структура MicroSD карты

Карта памяти должна быть отформатирована в **FAT16/FAT32** с именами файлов в стандарте 8.3:

* `BEEP.WAV` — эталонный стерео синус 440 Гц (16 бит, 44.1 кГц)
* `TRACK01.MP3`
* `TRACK02.MP3`
* `TRACK03.MP3`
* `TRACK04.MP3`
* `TRACK05.MP3`

---

## ⌨️ Команды Serial Monitor (115200 бод)

* `0` .. `5` : Запуск трека (`0` = `BEEP.WAV`, `1..5` = `TRACK01..05.MP3`)
* `p` : Пауза / Возобновление (Pause / Resume)
* `s` : Остановка воспроизведения (Stop)
* `+` : Увеличить громкость
* `-` : Уменьшить громкость
* `b` : Переключение Bass Boost (+0 / +6 / +12 / +15 dB)
* `e` : Переключение пространственного 3D звука EarSpeaker (0..3)
* `t` : Запуск аппаратного DSP синус-теста
* `l` : Список файлов на MicroSD
* `i` : Чтение регистров `SCI_STATUS` и `SCI_CLOCKF`, состояние плеера
* `?` : Справка по командам

## 🚀 Сборка и автоматический CI/CD

Проект настроен для сборки через **PlatformIO** и компилируется в облаке через **GitHub Actions**:
1. При каждом `git push` запускается workflow `.github/workflows/build.yml`.
2. Компилируется прошивка под ATmega328P с жесткой оптимизацией по размеру `-Os`.
3. Готовый бинарник `firmware.hex` выгружается в артефакты сборки (Artifacts).
